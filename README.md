# aev-pilot-sandbox

   Pilot repository for [Agentic Earned Value (AEV)](https://github.com/GunpreetSabharwall/agentic-earned-value).

   It holds small Python utilities built partly by an AI coding agent and partly by a person. The AEV GitHub Action runs every week and writes [AEV-REPORT.md](AEV-REPORT.md).

   - Settings and cost inputs: [`.aev/`](.aev/)
   - Workflow: [`.github/workflows/aev.yml`](.github/workflows/aev.yml)

   This is a small test pilot. The numbers show the tool working end to end. They are not evidence about real-world programs.
